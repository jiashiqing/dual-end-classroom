# 03 · 课堂管控组件

十二个组件，模板里都有实现。这里写「为什么这么做」和「怎么改」。

## 消息表（照这个加字段，别自创）

| `t` | 方向 | 载荷 | 触发 |
|---|---|---|---|
| `hb` | 教师 → 本班 | `open:[1,2]`, `sec`, `run`, `cfg`, `rank`, `n`, `pts` | 每 3 秒 + 状态一变就发（`pts` / `open` / `sec` 给手机遥控台补漏） |
| `cfg` | 教师 → 大厅 | `cfg`, `open`, `code` | 跟着每次心跳，给还没报到的学生 |
| `join` | 学生 → 教师 | `id,name,g,lv,done` | 报到成功 / 断线重连 |
| `prog` | 学生 → 教师 | `id,name,g,lv,done` | 过关、切关 |
| `ping` | 学生 → 教师 | `id` | 每 8 秒 |
| `help` | 学生 → 教师 | `id,name,g` | 点「举手」 |
| `score` | 教师 → 全体 | `g`, `d`, `why` | 老师加减分 / 规则自动加分（`why` 是给学生看的一句话，如「全员通关·第1个」） |
| `helpok` | 教师 → 该学生 | `id` | 老师点了他的抢答（学生端把按钮恢复成「举手」） |
| `mscore` | 手机 → 教师 | `g`, `d` | 手机遥控台点加分（**只发意图，不记账**） |
| `mlv` | 手机 → 教师 | `lv`, `on`（或 `all:1/0`） | 手机遥控台放行/收回某一关 |
| `mtimer` | 手机 → 教师 | `act`: `toggle` / `add` / `reset` | 手机遥控台开始暂停 / +5 分钟 / 归零 |
| `askpts` | 手机 → 教师 | — | 手机页刚连上，要一份分数 + 关卡 + 计时（不等 3 秒心跳） |
| `gpts` | 教师 → 全体 | `n`, `pts`, `title`, `code` | 分数一变就发；`pts` 是 `{组号:[auto,manual]}` 数组 |
| `ctl` | 教师 → 全体 | `open`, `sec`, `run`, `mins`, `lv`, `n`, `title` | 遥控动作后立刻发（手机据此重画关卡与计时条） |

约定：
- **消息要小**。`hb` 里带 `rank` 只带前 10 名，别带全量学生表。
- **教师端是权威**。学生上报只描述"我到了哪"，不描述"我该得多少分"。
- **学生端必须能忽略不认识的消息**（`if (m.t === …)` 兜底），否则将来加字段就白屏。

## 1 · 课堂码

4 位数字，教师端生成一次存 localStorage，学生端只做格式校验（`/^\d{4}$/`）。

- **放在「控制台 · 课前设置」，不要占大屏。** 它是「进门用的东西」：上课前亮一次，学生都进来了就不再需要占着一整屏；大屏那一屏要留给进度墙。大屏副标题里写一句"课堂码在控制台·课前设置"就够了。
- **别做服务端校验**：没有后端，校验就是"格式对就行"。它的作用是**把两拨人分开**，不是安全边界。
- 学生输错码也能进（本地闯关照跑），只是上报到没人听的频道。这是刻意的降级，不是 bug。
- 换码要同时重连（`Sync.connect` 用新码），并提示"学生要重新报到"。

## 2 · 二维码：现场算，别调接口

机房常年不联外网，在线二维码接口一律不考虑。模板带 `assets/qr.js`——一个零依赖的 QR 编码器（8bit byte 模式 + RS 纠错 + 8 种掩码按罚分择优，版本 1–10），只暴露：

```js
const r = QRCode.encode('http://192.168.3.87:8099/s?g=8', 'M');
r.size      // 边长（模块数）
r.modules   // size × size 的 0/1 方阵
```

画进 canvas 的三条硬要求：

1. **每模块取整数像素**：`px = Math.floor(660 / (size + 8))`。非整数会让模块边缘糊成灰，手机对焦失败——这是扫码成功率最大的一个变量。
2. **静区留 4 模块白边**，canvas 内部分辨率做大（600+），CSS 缩到 170~200 显示。投影和截图都清楚。
3. **拿不到教师机地址就不画**：整块换成橙色「教师机地址待确认」。画一个扫不出东西的方块比不画更耽误事。

**码里多带一个 `?g=<组数>`**：学生扫码进来第一眼就是对的组按钮，不用等大厅那一轮心跳。地址那一行照旧显示不带参数的短地址（学生手抄方便）。组数一改要重画，指纹里必须带上组数，否则会被"地址没变"挡掉。

### 学生机地址从哪来

老师机为了开摄像头常用 `http://127.0.0.1:8099/t` 打开，此时 `location.host` 是回环地址，直接显示会误导全班。做法：

- 浏览器给的 host 不是回环 → 就用它（那就是学生看到的）。
- 是回环 → `fetch('netinfo')`，服务端 `best_lan_ip()` 按 `192.168 → 10. → 172.16-31 → 其它 → 169.254` 打分挑一个内网地址，端口取 `server.server_port`（`--port` 被占会自动顺延，不能拿命令行参数糊弄）。

地址长度是变数（`192.168.3.87` 与 `192.168.100.100` 差 4 个字符），`fitStuUrl()` 从 18px 一级一级缩到 12px，**绝不折行**——折成两行学生就得照着两行抄。

## 3 · 小组：2–12 组，别写死

学生报到时选组，教师端所有统计按 `g` 聚合。

- 不要让学生自由输入组号（会出现"第三组""3组""三组"三种写法）。
- **组数是配置，不是常量**：4/6/8 只是快捷键，另给一个 2–12 的自定义输入。改完立刻影响三处：加分卡张数、进度墙行数、学情分组。
- **组数要能跨端同步**：报到页还没有课堂码，连不到本班频道，所以教师端每次心跳顺手往「大厅」频道播一份 `cfg`（见 02）。学生端报到页开一条独立 SSE 听大厅，收到就重画组按钮。
- **改组数时已经进课堂的学生**：自己那组没了要夹到最后一组并重报（`applyGroups`），否则教师名单里挂着一个空组。
- 老师那边根本没开（自习模式）时，报到页先按上限 12 画，老师把超范围的组号夹到最后一组。

## 4 · 计时：每关一个时长

```js
cfg.mins = [10, 12, 15, 12, 8]   // 长度必须等于 LEVELS.length
```

**不要退回「一个全局 `TIME_SEC`」**——课上五关的节奏本来就不一样，第三关常常要 15 分钟，第五关 8 分钟就够。教师端一份 `sec` 每秒递减，`run` 控制启停，随 `hb` 下发；学生端只显示，不自己算。

- **当前关 = 已放行里最大的那一关**（学生此刻在做的那关）。全部关闭时退回第 1 关，别让计时器变成一个没有归属的数字。
- **只有真的换关才重置倒计时**（`syncTimerLv` 记住 `_tlv`）。否则"顺手开一下第 2 关"会把正在跑的计时清零，老师当场懵。
- 换关后暂停（`run=false`），提示「进入第 3 关 · 7 分钟」，等老师点开始。
- 「+5 分钟」加在当关，「计时归零」回到当关时长。
- 显示成「第 3 关 · 07:00」，比"还剩 7 分钟"信息量大：老师要同时知道在讲哪一关。
- 剩 60 秒变红；到 0 就停，不要跑负。

## 5 · 关卡放行

教师端维护 `open: [1..n]`，学生端：

```js
unlocked(lv) = open.includes(lv) || done >= lv-1 || (cfg.jump && lv <= max(open))
```

- 默认只开第 1 关，老师点「放行下一关」逐关开；另给逐关开关行（点整行就切），课上临时收回某关很常用。
- **不要做成"全解锁开关"**：一节课的教学节奏就靠这个卡（`cfg.jump` 只是允许学生在已放行范围内回头补，不是全开）。
- 学生点已解锁但没过的关要能回访（老师讲评时常用）。
- 断网/无服务器时降级为全解锁，否则学生卡在第一关干等。

## 6 · 加分与小组积分：老师给的分 + 规则自动给的分

先分清两本账，别混：

| 账本 | 谁写 | 用来干什么 |
|---|---|---|
| `gpts[组] = {auto, manual}` | `auto` 由规则加；`manual` 由老师点 `+1/−1` | **组积分**，评「最优小组」只看这本 |
| 学生 `score` | 老师点 `+1` 时组里每人各记一笔 | 个人榜、学情表里的「得分」，纯展示 |

**组积分 = `auto + manual`**。老写法「把 1 分发给组里每个人再求和」是错的：6 人组点一下等于 +6，人数不对等的班立刻失真。**一次点击只给这一组 +1**，学生的 `score` 各记一笔是为了让学生端能弹「老师给你们加分了」。

### 自动分：三档，值写在一处

```js
const SRULE = { fin: [10, 7, 5], floor: 3, cover: 2 };
function SRULE_CV() { return Math.max(0, CONFIG.LEVELS.length - 1); }  // 覆盖分算到倒数第二关
```

| 项 | 触发 | 分值 |
|---|---|---|
| 冲线分 | 本组**全员**通过全部关卡，按到达先后 | 第 1 个 10 / 第 2 个 7 / 第 3 个 5 / 第 4 个起 3 |
| 覆盖分 | 前 N−1 关里，本组**所有人**都过了这一关 | 每关 +2 |
| 教师分 | 老师点 `+1 / −1` | ±1，建议单节 ≤10 |

三个取舍有理由，改之前先想一遍：**只奖励第一个会让后面的组散掉**（所以有覆盖分）；**最后一关全员通过就是冲线**（所以覆盖分只算到 N−1，不重复给）；**8 个组只奖前三等于一半人陪跑**（所以第 4 个起保底 3）。

### 判定：幂等 + 只在「有人往前走」时判

```js
judgeAwards() {                       // 调用点：onMsg 的 join / prog / help 之后
  for (g of 1..groups) {
    for (lv of 1..SRULE_CV()) {
      if (award.lv['g-lv']) continue;           // 已经发过
      if (!全员(g, lv)) continue;
      award.lv['g-lv'] = 1; addAuto(g, SRULE.cover, ..., quiet=true);
    }
    if (award.fin.includes(g)) continue;        // 只冲一次线
    if (!全员(g, LEVELS.length)) continue;
    award.fin.push(g);                          // 顺序即名次
    addAuto(g, SRULE.fin[名次] ?? SRULE.floor, ...);
  }
}
```

四条不能省的细节：

1. **`bye`（学生退出）不判定**。否则「最慢的那个人走了」，剩下的组白捡一个冲线。
2. **空组跳过**（`mem.length` 为 0 时 `every()` 恒真，会白送满堂分）。
3. **覆盖分不弹大屏 toast**（`quiet=true`）：8 组 × 4 关最多 32 次，每次都盖住底部 KPI 两秒；分数在墙上、榜上都会变，学生端各自也收到提示。只有冲线值得打断全班。
4. **判定要跑在 `render()` 之前**，否则会闪一下「分已上榜、进度还是旧的」。

### 排名与并列

`总分 → 冲线先后（没冲线的排最后）→ 平均已过关数 → 组号`。三级兜底保证任何时刻名次确定，不会每次刷新换位置。

### 换成本班规则

只改 `SRULE` 一处；`csvGroup()` 的规则摘要、榜单满分提示都从它读。**改分值不改已经发出去的分**（那是历史事实，不是配置）。

### 独立成页 + 手机端（`/m`）

加分是课上点得最频的操作，挂在「控制台 → 课堂运行」里要点两层、还会把逐关开关挤下去。所以它单独一个页签，右栏再挂一张**手机遥控台**的二维码。

- 手机页是 `assets/mobile_remote.html`，构建时改名成 `遥控台.html`，由 `GET /m`（也认 `/score` `/remote`）直接吐出来。它和教师端是**两个独立文件**：手机不该加载整个教师端（投屏布局 + 摄像头），教师端也不该为手机改样式。
- **一个码管三件事**：加分、逐关开放、计时。所以「加分」页右栏那张大码和「控制台 · 课堂运行」里那张小码画的是同一个 URL —— 老师站哪一页扫都一样，不用记两个码。两处共用 `T.paintQRm()`（两张 canvas 一次画完）。
- **唯一记账方是教师机**：手机只发 `{t:'mscore',g,d}`，教师端 `addScore(g,d,true)` 落账后广播 `{t:'gpts',n,pts}`；心跳里也带一份 `pts`，漏一条也能补上。手机本地先加一下只为手感，下一帧就被覆盖 —— 别让手机自己记账，两台手机各点一下分数就翻倍。
- **`pts` 必须是 `{组号: [auto, manual]}` 数组**：内部那套 `{auto, manual}` 直接发过去，手机端读 `p[0]/p[1]` 会全是 0（探针抓到过这个 bug）。
- 手机页要拦「没连上」的点击：教室后排 Wi-Fi 抖动时，点了没反应比报错更让人抓狂。
- **放行与计时也只递意图**：`{t:'mlv',lv,on}` / `{t:'mtimer',act}` 落到 `T.remoteLv()` / `T.remoteTimer()`，两者分别复用 `afterOpen()` 与面板按钮那一套副作用（`syncTimerLv()` 会自己判断「换了关才重置倒计时」）。千万别在手机侧另写一份「设置 open 数组」的逻辑，否则换关语义两边会长歪。
- **手机页有个吸顶计时条**（`position:sticky`）：一路滚到第 8 组加分时，剩余时间和开始/暂停仍钉在顶上。手机上的秒数靠自己每秒走一格，`ctl` / `hb` 一到就校回教师机的值。
- 卡上三个按钮：`−1`（点错回退）、`+1`（常用）、`+5`（整组过一关之类的奖励）。**一次点击只加这么多**，不按人数乘。

## 7 · 举手抢答

学生端点「🙋 举手」→ 发 `{t:'help',help:true}` → 大屏右栏按**举手先后**排队，名字前挂 `1/2/3` 顺序号。老师照着号点人，不用每次问「谁先举的」。**不做弹窗**：老师正在讲课，弹窗是打扰。

- **排序靠 `helpAt`**，只在「放下 → 举起」那一刻写时间。没有它就只能按名字/上报顺序排，第二个人一举手可能插到第一个前面。
- **放下再举要排到队尾**：`helpAt` 重写为当前时刻，符合课上「重新举手」的直觉；原地保留旧序号会让人觉得系统坏了。
- 老师点一下某一行 = 「这题他答了」：本地清 `help`，再发 `{t:'helpok',id}` 通知该学生（他那边按钮恢复成「举手」，并提示一句）。不发这一条，学生那颗按钮会一直亮着。
- 红点要能自己消失：学生下次 `prog` 上报 `help:false` 自然清掉；只显示还在线的人（离线的不该继续占着队列）。

## 8 · 本课任务（学生端弹窗 + 顶栏常驻入口）

老师写标题 + 正文发布 → 学生端**当场弹一次**（还在报到的，进课堂时补弹）→ 关掉后顶栏「任务」按钮常驻，任何页面点它都能再看。

- **不新建通道**：`cfg.task={title,text}` 跟着心跳下发，学生端 `syncTask()` 自己比对新旧内容。数据只需要「最新一份」，搞一张任务表纯属多余。
- **弹的时机**：内容变了、或者这次进课堂还没弹过（`_taskShown`，`enter()` 时归零）。只弹这两种，否则学生关一次弹一次就是骚扰。
- **老师清空 → 弹窗自己收**，顶栏按钮一起隐藏；此时再点它只提示「老师还没发布任务」，不弹空窗。
- 正文先 `esc()` 再按 `\n` 切 `<br>`：老师可能贴进来带尖括号的内容，直接 innerHTML 就是 XSS。
- 学生端**不缓存**任务内容（不进 `session`），永远显示老师最新那份。

## 9 · 进度墙 + 全屏看板

大屏那面墙回答「**哪个组到哪一关**」：一行一个组、一格一关、格内数字＝这一组到这一关的人数、绿柱＝比例。**最右一列是组积分**（跟墙贴在一起看：进度和分在同一行上）。墙下面才是四个 KPI（在线 / 已通关 / 平均关数 / 当前领先）——它们是"全班概况"，跟墙贴在一起看最顺。

要点：

- **行高等分**：`.wall{display:flex;flex-direction:column}`，行 `.wrow{flex:1 1 0}`，表头行 `flex:0 0 auto`。8 组时约 40px，组数一多自动压扁；`>9 组`给 `#wall` 加 `dense`（数字 22→16px、gap 6→4px），12 组 13 行也一行不少。
- **加列不要收窄格子**：组名那列从 62/86 加到 76/100（要挂「冲」徽标），新加的积分列 46/84，中间 5 个关卡格用 `minmax(0,1fr)` / `flex:1 1 0` 自己吸收。
- **冲线徽标别用 🏁**：深色底上 emoji 会渲染成一小块黑，投屏更糊；用金色描边小字「冲」。而且 `.wg` 如果是 `display:grid`，文本和 `<i>` 徽标会各占一整行（组名一行、徽标掉到下一行）——**改成 flex + `gap:4px`**。
- **加内容前先量余量**：外层是定高的，往墙里加一行就得先压别处。量的正确姿势是「最后一个子元素的 `rect.bottom`」与「面板底边 − paddingBottom」之差 —— 面板自己是 flex 列会被压缩，量它的 `scrollHeight` 恒等于 `clientHeight`，永远看不出溢出。
- **全屏看板挂舞台根节点**：`#stageArea` 可能只有 992 高（顶栏吃掉 88），放进去"铺不满一屏"；挂在 `#stage`（1920×1080、`position:absolute`）里才能 `inset:0` 铺满，靠更高的 `z-index` 盖住顶栏，并跟着舞台 `transform:scale` 一起缩放。没有固定舞台的项目用 `position:fixed;inset:0` 等价。
- **看板内容**：一组一块，组名 + 人数 + 「N 人全通关」徽标；每人一张卡＝姓名 + 五段进度条 + 已过 N/5 + 当前第几关。全部通关变金色，离线压暗**但不隐藏**——名单是老师点名的依据。
- **用内容指纹挡重绘**：看板每 4 秒跟数据刷，但内容没变就别重建 DOM，否则滚动位置每 4 秒被拉回顶部。最省事的写法是全局 `setHTML(el, html)`（`el.__h === html` 就跳过），大屏、排行榜、看板、名单都能用。
- 关闭：右上按钮 + `Esc`；**换页/切页签也要自动收起**，不能挂着挡别的页。

## 10 · 学情导出 CSV

```
姓名,小组,已过关,得分,状态,最后活跃
```

- **第一行加 `\ufeff`（BOM）**，否则 Excel 打开中文乱码。
- 文件名带课堂码，避免多节课数据混在一起。
- 页面上明确写「数据只在本机浏览器，下课就导走」——这类工具最常见的投诉是"上节课的数据没了"。
- **另出一张「小组积分」表**（`csvGroup()`），因为名单是过程数据、评优要的是结论：

```
名次,小组,人数,总积分,自动分,教师分,冲线名次,平均已过关,全员通关
```

  末行附一句规则摘要（从 `SRULE` 生成），文件离开文档也能看懂。分项列（自动 / 教师）一定要留：老师被问「这分怎么来的」时，能当场拆开。

## 11 · 学情 AI 分析：把数据交给模型，出一份课后分析

老师看完条形图知道「第 3 关只剩 8 人」，但不知道「下节课该补什么」。这一块把整节课的数据打包成一段文本交给大模型，出一份**总评 → 关键发现 → 卡点诊断 → 下一步建议 → 值得表扬**的课后分析。

- **只填一个 Key 就能用**：厂商预设 12 家（默认 DeepSeek），接口地址与模型名都跟着预设走，老师不需要知道 `base_url` 是什么。换厂商 = 换下拉，**不用改代码、不用重构建**。
- **除 Claude / Gemini，其余全是「OpenAI 兼容」**：差别只在 base 与模型名。花力气写"支持大部分模型"，实际就是写三个 `mode`：`openai` / `anthropic` / `gemini`。
- **必须走本机服务器转发**（`POST /api/llm`，见 `02`）：页面直连会被 CORS 拦，Key 也不该落在页面上下文。
- **整屏面板，不塞进学情卡片**：400~600 字在 1366×768 的卡片里放不下，挤掉表格更糟；做成整屏还能投屏讲评。
- **流式渲染**：`requestAnimationFrame` 合帧（一个回答 150~300 帧），只在用户贴着底部时才自动滚到底。
- **数据口径就是老师看到的东西**：每关通过人数（带环比流失）、各组人数/平均/积分、学生明细一人一行。`cfg.real === false`（大屏不显示真名）时**发给模型的也是「同学07」**——隐私设置要一路生效，不能只在大屏上生效。
- **可不传的东西一律不传**：课件、图片、视频、摄像头画面、录音，一个都不发。
- **结果不落盘**：刷新即丢，要留档用「复制结果」。
- 出错要**落到面板上**，不要只 `toast`：`上游 401：Invalid API key provided` 老师才知道是 Key 的问题。状态必须收尾（按钮从「分析中…」回到「重新分析」），否则老师会以为卡死。

## 12 · 证书：可领，但有门闩

学生端全部通关后生成，canvas 画图 + `toDataURL` 下载 PNG（不引依赖，断网可用）。

**门闩两道，缺一不可**：

1. **展示层**：顶栏那颗证书按钮按 `done` 加/去 `locked` 类（`opacity:.4 + cursor:not-allowed`，**不隐藏**——学生得知道有这张证可领）。
2. **入口层**：点击里再拦一次，`toast('还有 N 关没通过')`。

只在 CSS 上隐藏，学生按 Tab/回车或直接调函数照样能领；只拦点击不改样式，学生不知道要做什么。两道都在才绕不过去。

其它要点：
- 字体写死中文系统字体（`"Microsoft YaHei"`），别指望服务器字体。
- 名字过长要截断，别让 `fillText` 溢出画布。
- 文件名带学生姓名，老师收作业能认出来。

## 扩展题型

`content(lv)` 返回 `{title, qs:[{q, a:[...], k:正确下标}]}`。要加题型：

1. 在 `qs` 里加字段区分（`type:'multi'` / `type:'input'`）
2. 在 `openTask` 里按 `type` 渲染（拆成 `renderChoice` / `renderInput` 两个小函数，别在一个 if 里堆）
3. 在 `submit` 里按 `type` 判分
4. **判分逻辑只写一次**：`judge(q, picked)` 返回布尔，别在两处各写一遍

拖拽、作图这类需要指针事件的，先确认目标设备是鼠标还是触摸——机房一般只有鼠标，别为触摸优化到鼠标用不了。
