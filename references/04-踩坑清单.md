# 04 · 踩坑清单

全部来自真实项目，按「现象 → 原因 → 解法」写。遇到类似症状直接对号。

## A. 架构与代码

### A1 教师端里跑的是旧版学生流程

**现象**：教师端 HTML 里点「学生端」，进去的界面跟学生手上那份不一样，文字还提示"请打开学生端网页"——而人就在网页里。

**原因**：一个 HTML 装两套代码、靠角色页切换。某次只升级了学生端那份文件，教师端里内置的那份停在三代之前。两份文件各自被手工改过，必然分叉。

**解法**：一份源码 + 构建裁剪（本技能 `build_dual.py`）。角色锁只能"看不见旧代码"，裁剪才能"没有旧代码"。

### A2 写了角色锁，以为就隔离了

**现象**：`window.__PURPOSE__='B-teacher-only'` + 加载时自动 `btn.click()` 跳过角色页，看起来万无一失。

**原因**：这是"看不见"，不是"不存在"。自动点击一旦失败（脚本报错、被扩展拦、DOM 变更），角色页就露出来，点另一个角色直接掉进旧流程。

**解法**：锁可以留，但**主要靠构建裁剪**。另外给另一端的入口改成"新标签打开对方文件"，而不是"进入本文件里的旧模块"。

### A3 用覆盖 `window.prompt` 的钩子代答口令

**现象**：为了让教师端自动进面板，钩子里写了 `window.prompt = () => '1578'`。

**原因**：原生 `prompt` 在部分壳里被拦，作者图省事直接覆盖。副作用是：**这份文件在任何环境下都没有口令了**，而且覆盖期间用户自己触发的 prompt 也会拿到固定值。

**解法**：不要用 `prompt` 要口令。教师端文件本身就不该发给学生；真需要锁就在页面里放输入框，别做假锁。

### A4 第三方同步服务 key 明文进 HTML

**现象**：`_GEAKEY: 'BC-e8612e7f…'` 写死在两份文件里，频道名只是 `前缀_4位码`。

**原因**：纯前端只能用公开 key。任何一个学生按 F12 就能拿到，然后连同一频道发假分数。

**解法**：默认走内网自建服务器（本技能）。真要公网，就必须上后端鉴权，纯前端没有安全方案。

### A5 把"可变配置"写成了常量

**现象**：分组数写死 8、五关共用一个 `TIME_SEC`。上线后第一条需求就是"我们班 10 个组""第三关能不能给 15 分钟"，于是要动渲染、动统计、动存储，改一圈。

**原因**：把"这节课的具体取值"当成了"系统的形状"。组数、时长是老师每节课都可能改的东西，不是常量。

**解法**：分两层——`CONFIG` 放形状（关卡列表、上下限、间隔），`cfg` 放取值（`groups`、`mins[]`、`title`、开关），`cfg` 存 localStorage 并随心跳整块下发。`mins` 一开始就用数组，别等被要求"每关不一样"再改模型。

### A6 配置项和它驱动的控件被切在两个页签

**现象**：「总控」页有加分卡（张数由分组数决定）、「设置」页能改分组数；老师改完得来回翻页看有没有生效。每关时长也一样：设置页填、总控页用。

**原因**：按"功能"分页（控制 / 设置），而不是按"使用时序"分页。

**解法**：合成一个「控制台」，页内两个视图（`课堂运行` / `课前设置`）。运行视图高频、设置视图低频，用视图分开就不会误触；配置项和它驱动的控件在同一页，改完立刻能看见结果。

## B. 同步与服务器

### B1 无头浏览器测页面，`setTimeout` 永远不触发

**现象**：`--virtual-time-budget=8000 --dump-dom` 打开页面，只跑到第一个定时器就卡住，后面的动作全没发生；`--dump-dom` 甚至超时不返回。

**原因**：SSE 是长连接。加了 `--virtual-time-budget` 之后，浏览器要等"网络空闲"才推进虚拟时钟，而 SSE 永不空闲 → 虚拟时钟冻结 → 页面里的定时器停摆。

**解法**：测交互流程时**别用 `--virtual-time-budget`**。改成真时间后台跑浏览器、到点杀进程，用"服务器收到了哪些消息"来判定。只想验首屏渲染时，用 `?relay=127.0.0.1:9`（拒绝连接）把同步层短路掉。

### B2 302 短地址在命令行工具下 404

**现象**：浏览器打开 `/s` 正常，`curl`（跟随重定向）404，`http.client` 正常。

**原因**：`Location` 里是已编码的中文路径（`%E5%AD%A6…`），部分客户端跟随重定向时会二次编码成 `%25E5…`。

**解法**：不跳转。服务端改写 `self.path` 后直接返回文件，一个请求一个响应。

### B3 一节课下来服务端线程和队列爆掉

**现象**：学生进出几轮后 `/healthz` 里的订阅数只增不减，内存缓慢上涨。

**原因**：SSE 是单向流，服务端不写就不知道对端走了；而 socket 关闭后的**第一次写经常"成功"**（进了内核缓冲区），只靠写异常判断会漏掉。

**解法**：心跳时 `select.select([conn],[],[],0)` + `recv(1, MSG_PEEK)` 读到 `b''` 就退出并 `_leave`。实测断开后 18 秒内清干净。

### B4 学生端把心跳当成真消息

**现象**：学生端每隔 15 秒有一次莫名的消息回调，日志刷屏。

**原因**：心跳用了 `data: {"t":"hb"}` 这种帧，会触发前端 `onmessage`。

**解法**：心跳用 SSE 注释帧 `: hb\n\n`，浏览器不会派发 `onmessage`。

### B5 自己的测试断言写错了，还以为代码有 bug

**现象**：跨频道隔离测试报"串了 1 条"，检查半天服务端没问题。

**原因**：断言写成了"旁听频道应该收到 0 条"，但旁听频道自己也发了一条——它本来就该收到自己频道那条。

**解法**：隔离要写成三条：旁听频道**只**收到自己那条；主频道**不含**别频道发送者；两边条数各自对。测试写错比代码写错更常见，报错先怀疑断言。

### B6 老师改了组数，学生端报到页还是 8 个按钮

**现象**：教师端把分组数改成 10，加分卡和进度墙都变了，学生机的组按钮还是 8 个；刷新也没用。

**原因**：组数只在 `hb` 里下发，而 `hb` 走的是**本班频道** `de_v1_<课堂码>`。报到页还不知道课堂码，压根没连上那个频道——它收到的东西永远是空的。

**解法**：加一条「大厅」频道 `de_v1_lobby`。教师端每次心跳顺手播一份 `{t:'cfg', cfg, open, code}`；报到页用 `Sync.subscribe()` 另开一条 SSE 听大厅（不是把主连接改到大厅——主连接要留给报到后的课堂频道）。报到成功后 `Lobby.stop()`。

扫码进来的那条 `?g=<组数>` 只是让第一眼就对，不能替代大厅：手输地址的人没有参数。

### B7 大厅频道里塞了整份排行榜

**现象**：加了 `cfg` 广播后，学生报到页在几十人同时开着时明显卡顿、风扇响。

**原因**：偷懒把 `hb` 整个对象播到大厅，里面带 `rank`（前 10 名）和全量状态；几十个还在报到页的机器每 3 秒各收一遍。

**解法**：大厅那条**只带配置**（`cfg` / `open` / `code`，几百字节）。排行、名单、计时数值都只走本班频道。

## C. 页面与样式

### C1 投屏页内容全挤在上半屏

**现象**：教师端「大屏」页两张卡片顶在上面，下半屏一大片空白，投出去很难看。

**原因**：`tab` 内容是普通块流，`min-height` 没撑满视口。

**解法**：`#tab-teach.on{display:flex;align-items:center;min-height:calc(100vh - 122px)}`（122 = 页签栏 + 内边距）。注意 `#tab-teach.on` 要压过 `.tab.on{display:block}` 的优先级。

### C2 教师端点名册把栅格撑破

**原因**：`grid-template-columns:1fr 1fr` + 长名字/长列表。

**解法**：`minmax(0,1fr)` + 子元素 `min-width:0`。这类问题只在真实数据出现时才爆，别用「张三」测试。

### C3 `hidden` 属性不生效

**原因**：flex/grid 子元素上 `display` 被布局规则覆盖，`hidden` 的默认样式输掉。

**解法**：CSS 顶部写 `[hidden]{display:none!important}`。

### C4 1366×768 上字小到看不清

**原因**：按 1920 设计稿写字号，投到 1366 等于打六六折。课堂码写 48px 实际只剩 32px，最后一排看不见。

**解法**：课堂码 ≥56px、正文 ≥16px、按钮 ≥18px。判据是"最后一排能不能看清"，不是"我觉得够大"。

### C5 localStorage 教师状态和学生进度互相覆盖

**原因**：两端用同一个 key 前缀。

**解法**：`de_<ROLE>_<key>`，`ROLE` 由构建注入。顺带好处：同一个浏览器里可以同时开教师端和学生端互不干扰。

### C6 旧存档迁移把默认值当成了"有值"

**现象**：老版本存的是 `{minutes:20}`，升级后五关时长全变成 12（默认值）；或者反过来，新装的机器上默认的 `[10,12,15,12,8]` 被统一成了 12。

**原因**：先 `Object.assign(DEFAULTS.cfg, saved)` 再判断合并结果 `if (!cfg.mins)…`。`DEFAULTS` 里本来就有 `mins`，合并之后永远"有值"，迁移分支要么永不触发，要么用错值。

**解法**：**判断落在存档对象自己身上**，并且**只在真的有存档时迁移**：

```js
const sc = Store.get('cfg', {}) || {};
const hasSaved = Object.keys(sc).length > 0;
this.cfg = Object.assign({}, DEFAULTS.cfg, sc);
if (hasSaved && (!Array.isArray(sc.mins) || sc.mins.length < LEVELS.length)) {
  const m = clamp(+sc.minutes || 12, 1, 90);
  this.cfg.mins = LEVELS.map(() => m);
}
```

### C7 改组数后，被夹到末组的学生没重报

**现象**：老师把 8 组改成 6 组，第 7、8 组的学生界面改成 6 组了，但他们原来那个组在老师名单里还挂着，进度墙上是空行。

**原因**：

```js
applyGroups(n){
  if (this.g > g) { …report… }   // 错：paintGroups 里已经把 this.g 夹到 g 了
  this.paintGroups(g);
}
```

`paintGroups` 会把越界的 `this.g` 夹到末组，所以之后再比较 `this.g > g` 永远为假。

**解法**：**先存 `was` 再重画**：

```js
const was = this.g;
this.paintGroups(g);
if (this.joined && was > g) this.report({ t:'join' });
```

### C8 二维码画出来了，但手机扫不出来

**现象**：教师端二维码看着是张码，微信扫半天没反应，或者扫出来是个错地址。

**原因**（按出现频率排）：

1. **模块像素不是整数**：`px = 660 / (size + 8)` 直接除，边缘被抗锯齿糊成灰，模块分不开；
2. **没留静区**：码贴到 canvas 边界，四角定位块被切；
3. **canvas 显示尺寸太小**：内部只有 100 来 px，投影到墙上就糊；
4. **编的内容不是学生真能访问的地址**：把 `127.0.0.1` 编进去了。

**解法**：`px = Math.max(4, Math.floor(660 / (size + 8)))`；留 4 模块白边；canvas 内部 600+、CSS 缩到 170~200；地址取自 `/netinfo`，拿不到就不画（换橙色提示）。验的时候别靠眼睛——用 OpenCV `QRCodeDetector` 解码回原文，或者手机实拍一张。

### C9 全屏看板"铺不满一屏"

**现象**：点「详情」，看板只占了上面一块，下面是空白；顶栏还压在它上面。

**原因**：挂在了内容区（`#stageArea`，高度 = 1080 − 88 顶栏）里，且 `z-index` 不够。

**解法**：挂到舞台根节点（`#stage`，1920×1080 绝对定位）+ `inset:0` + 高于顶栏的 `z-index`。它跟着舞台 `transform:scale` 一起缩放，投屏不用另调。没有固定舞台的项目用 `position:fixed;inset:0`。

### C10 面板溢出了，但量 `scrollHeight` 是 0

**现象**：明明看到最下面一行被切掉，脚本量 `.panel.scrollHeight - clientHeight` 却是 0。

**原因**：面板是 flex 列、外框上下被钉死，子元素超出时是被**压缩/裁掉**，不会让容器的 `scrollHeight` 变大。

**解法**：量「最后一个子元素的 `rect.bottom`」与「面板底边 − `paddingBottom`」之差。往这面墙里加行之前先量一次，比截图肉眼找快得多。

### C11 每 3 秒重绘一次，滚动位置被拉回顶部

**现象**：全屏看板人一多要滚动，但每 4 秒自己跳回最上面。

**原因**：每轮数据都无条件 `el.innerHTML = html`，即使内容没变也会重建 DOM。

**解法**：内容指纹挡一道：

```js
function setHTML(el, html){
  if (!el) return false;
  if (el.__h === html) return false;
  el.__h = html; el.innerHTML = html; return true;
}
```

绑事件的地方要用返回值判断"是否真重建了"，别在没重建时重复绑（会绑两遍）。

## D. 交付与运行

### D1 `.bat` 里的中文变乱码 / 文件跑不起来

**原因**：Windows 批处理默认按系统代码页解析，UTF-8 中文注释+CRLF 混合会出问题（GBK 老文件更糟）。

**解法**：`.bat` 只写 ASCII + CRLF，所有中文提示交给 Python 打印。启动器只负责找到 `py`/`python` 并转发参数。

### D2 教师机没装 Python

**现象**：双击 `start_server.bat` 闪一下就没了。

**解法**：`.bat` 里 `where py` → `where python` 都找不到时打印明确指引（去哪装、要勾哪个选项）。文档里写明"只有教师机需要 Python，学生机什么都不用装"，并给出退路（直接双击 HTML，走单机模式，只是看不到学生）。

### D3 Excel 打开导出的 CSV 是乱码

**原因**：UTF-8 无 BOM。

**解法**：`'\ufeff' + csv文本`，Blob 类型写 `text/csv;charset=utf-8`。

### D4 中文文件名在服务器上取不到

**原因**：`href="/学生端.html"` 未编码，或编码后被二次处理。

**解法**：服务端统一 `quote()`；短地址用内部改写（见 B2）。产出文件名里不要出现 `/ \ : * ? " < > |`。

### D5 只发了两个 HTML，二维码是空白

**现象**：老师把 `dist/` 里两个 HTML 拷到 U 盘带到教室，打开教师端，课堂码下面那块是空的（或者写着"二维码组件没加载"）。

**原因**：`qr.js` 是独立文件，用 `<script src="qr.js">` 引，漏了它就 `typeof QRCode === 'undefined'`。

**解法**：**交付物是"两个 HTML + `qr.js` + `sync_server.py` + `start_server.bat`"整个目录**，不是两个 HTML。构建脚本会一起拷并校验引用，手动搬文件时别只挑 HTML。

### D6 无头截图卡死，进程一直不退出

**现象**：`msedge --headless=new --screenshot=… --virtual-time-budget=4000` 跑了两分钟不返回，图也没出来。

**原因**：页面里有 SSE 长连接，虚拟时钟永远等不到"网络空闲"。同一个坑见 B1。

**解法**：截图**别加 `--virtual-time-budget`**，让它在 `load` 后直接拍；需要"先切到某个视图再拍"时，别靠页面里的 `setTimeout`，直接把 HTML 里 `hidden` 属性换掉生成一个静态副本再拍。另外每次截图用**独立的 `--user-data-dir`**：同一个 profile 被上一次没退干净的进程占着，第二次会静默失败（表现是两次截图 md5 一样）。
