# 05 · 交付与验收

## 五个脚本的分工

| 脚本 | 验什么 | 耗时 | 什么时候跑 |
|---|---|---|---|
| `verify.py` | 静态：角色隔离、外链、语法、标记残留、（可选）渲染 | 3 秒 | 每次构建后 |
| `smoke_sync.py` | 协议：静态托管、双订阅广播、跨频道隔离、掉线回收 | 3 秒 / 加 `--reclaim` 约 20 秒 | 改过服务端或协议后 |
| `e2e_ui.py` | 真浏览器：报到 → 答题 → 过关 → 上报 | 约 15 秒 | 交付前，需 Edge |
| `probe_ai.py` | 学情 AI 分析：面板铺满、流式增量、markdown 渲染、prompt 带数据、401 归一化、Esc | 约 20 秒 | 改过 AI 面板或服务端转发后；需 Edge + `websocket-client` |
| `probe_score.py` | 小组积分：冲线 10/7/5 顺序、覆盖分只算前 N−1 关、教师分不乘人数、幂等、两榜切换、进度墙积分列、清空归零 | 约 15 秒 | 改过 `SRULE` / 判定 / 榜单后；需 Edge + `websocket-client` |

一条龙：

```bash
python scripts/build_dual.py app.src.html --out dist --name 我的课堂
python scripts/verify.py dist
python scripts/smoke_sync.py --dir dist --reclaim
python scripts/e2e_ui.py --dir dist
python scripts/probe_ai.py --dir dist          # 自带假模型，不吃真 Key
python scripts/probe_score.py --dir dist       # 小组积分（不用真 Key，也不用真学生）
```

`probe_ai.py` 会自己起一个假上游（OpenAI 兼容的 SSE，逐帧吐 markdown）和一个真 `sync_server`，
页面里把厂商选成「自定义接口」指过去——所以**整条链路是真跑的，只有最后一段是假模型**。
没装 `websocket-client` 会打印一行"跳过"并返回 0，别把它当成通过。

`probe_score.py` 不造假上游，它直接调 `T.onMsg()` 模拟学生的 join/prog —— 因为要验的是「分算得对不对」，不是网络。它会先把 12 个学生按 `done:0` 报到，再一关一关往上推，所以「刚报到不该有分」「必须先报到才有全员」这两条也一起验了。

## 输出怎么读

### verify.py

```
双端课堂示例-教师端.html  21.6 KB
  外链 0 处
  script 块 1 个
    #0 len=10601  OK
  角色隔离：通过
  标记残留：无
```

- **外链 > 0** → 必须本地化，机房断网会白屏。常见来源：CDN 字体、图标库、`//cdn…` 协议相对地址。注意 `<script src="qr.js">` 是本地的，不算外链。
- **角色隔离：串味** → 说明某段角色专属代码没放进 `#if` 标记里。典型是启动分支 `if (ROLE==='T') T.init()` 漏标。
- **标记残留** → 构建没清干净，产物里还留着 `#if`，说明源码里有嵌套写错或标记行夹了别的代码。
- **找不到 node** → 语法检查自动跳过，只会有静态结果。别把"跳过"当成"通过"。

产物目录里必须有 `qr.js`。构建脚本会校验"HTML 引了 qr.js、目录里也有"；手动组装时自己检查一眼，漏了二维码会静默变空。

### 常见故障对照

| 现象 | 先查 |
|---|---|
| 二维码那块是空的 / 写着"二维码组件没加载" | `qr.js` 在不在 HTML 同目录；浏览器 F12 有没有 404 |
| 写着「教师机地址待确认」 | 服务端是不是老版本（没有 `/netinfo`）；`http://IP:端口/netinfo` 能不能出 JSON |
| 扫出来的地址是 `127.0.0.1` | 教师端是用回环打开的且 `/netinfo` 没生效，看 03 第 2 节 |
| 老师改分组数，学生报到页不变 | 大厅频道有没有在播 `cfg`（`/healthz` 里应能看到 `de_v1_lobby` 的订阅数）；服务端是不是单实例 |
| 学生安静 20 秒后全班"离线" | 学生端 `ping` 定时器在不在（`PING_MS` 必须小于 `OFFLINE_MS`） |


### smoke_sync.py

```
/s   200  23348 字节
广播返回人数：2 / 2 / 跨频道 1
A 收到 2 条，B 收到 2 条，旁听频道 1 条
healthz：{'ok': True, 'channels': {}}
```

- `n` 是**服务端实际写入的队列数**。学生端显示"已连接"但 `n` 是 0，说明订阅建立了但没进这个频道（码不一致）。
- `channels: {}` 才是对的：退出后所有订阅都该被回收。这里不空就是 B3 那个坑。

### e2e_ui.py

```
订阅端收到 2 条：['join', 'prog']
  join  → 姓名 测试甲 / 第 3 组
  prog  → 已过关 1 关
```

- 只看到 `join` 没有 `prog`：答题或判分有问题。用「往 `/send` 发诊断消息」的办法定位（模板见本技能开发过程：在自动化脚本里把 `S.picked`、`#s-msg` 文本、按钮数量一起发出来）。
- 两条都没有：页面 JS 没跑起来（语法错/抛异常/页面不是学生端）。

## 交付前人工看一遍

脚本查不出"难看"，也查不出"扫不出来"，这几条必须眼睛过（或手机过）：

- [ ] 1366×768 下教师端「大屏」：进度墙最后一行没被切、三个 KPI 完整、右栏排行榜和举手不重叠
- [ ] 「控制台 · 课前设置」：课堂码 4 位能隔着教室看清，二维码**用手机真扫一次**能进学生端，学生机地址不是 `127.0.0.1`
- [ ] 改分组数 8 → 10：加分卡变 10 张、进度墙变 10 行、学生报到页 3 秒内变 10 个按钮
- [ ] 改第 2 关时长为 7 分钟 → 点「放行下一关」：顶栏胶囊变成「第 2 关 · 07:00」
- [ ] 点「⛶ 详情」铺满整屏、能滚、`Esc` 能关、切页签会自动收起
- [ ] 学生报到页：组按钮一行排得下（12 组也不折行），输入框可点，按钮不塌
- [ ] 学生只过一关时，证书按钮是灰的；点它只提示不解锁
- [ ] 学生过完全部关卡，教师端名单立刻出现该学生且进度对
- [ ] 导出 CSV 用 Excel 打开，中文不乱码
- [ ] 证书下载的 PNG 名字带学生姓名
- [ ] 学情页填一个真 Key 点「开始分析」：文字**一段段冒出来**；换成错 Key 能看到「上游 401」红条
- [ ] 学情 AI 面板里换一个厂商（比如智谱 glm-4-flash），模型名与接口地址自动跟着变，不用手改

## 上课三步（写给老师的，抄进交付说明）

1. 教师机双击 `start_server.bat`，黑窗口别关，记下打印的地址
2. 教师机浏览器开 `http://127.0.0.1:8099/t`；学生机开 `http://本机IP:8099/s`（或直接扫「控制台 · 课前设置」里的二维码）
3. 把「控制台 · 课前设置」里的 4 位课堂码念给学生；下课点「学情」→「导出 CSV」

## 没装 Python 怎么办

只有教师机需要 Python（3.8+，安装时勾 `Add python.exe to PATH`）。装不了时的退路：

- **单机模式**：直接双击两个 HTML，识别/答题/闯关照跑，老师看不到学生进度，只能靠走场。
- **换一台机器**：任何装了 Python 的笔记本都能当服务器，学生连那台机的 IP。
- 教室有 NAS / 树莓派且能跑 Python，也可以把 `sync_server.py` 放上去。

## 版本与归档

| 动作 | 做法 |
|---|---|
| 发版 | `dist/` 整目录打包（两个 HTML + `qr.js` + `sync_server.py` + `start_server.bat`），别只发 HTML |
| 存档 | 保留 `app.src.html` + 当时的 `dist/`，两者版本号一致 |
| 改需求 | 只改 `app.src.html`，重新构建；**绝不手改 `dist/` 里的产物** |

`dist/` 可以随时删了重建。源码丢了两份产物就是死代码。
